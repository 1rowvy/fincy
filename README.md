# Fincy

Настольное приложение для учёта личных финансов. Доходы и расходы, счета,
бюджеты, регулярные платежи и цели накоплений — в одном окне, с графиками и
прогнозом.

**Все данные хранятся только на вашем компьютере.** Никаких аккаунтов,
регистрации, облака и подключения к интернету — кроме проверки обновлений.

## Установка

1. Откройте страницу [Releases](https://github.com/1rowvy/fincy/releases/latest).
2. Скачайте установщик для Windows (`Fincy_x.y.z_x64-setup.exe` или `.msi`).
3. Запустите его и следуйте шагам мастера.

Приложение само проверяет наличие новой версии при запуске и предлагает
обновиться в один клик. Проверить вручную можно в **Настройки → Проверить
обновления**.

## Возможности

### Счета
Наличные, карты, текущие и накопительные счета. Баланс считается автоматически
из начального остатка, всех операций, переводов и корректировок — вручную его
вводить не нужно. Между счетами можно делать **переводы**. Для накопительных
счетов есть **корректировка баланса**: просто впишите текущую сумму, не заводя
каждую операцию.

### Транзакции
Доходы и расходы с категорией, заметкой и тегами. Список фильтруется по счёту,
категории, тегу, типу, диапазону дат и тексту заметки.

### Бюджеты
Месячный лимит на категорию. Прогресс-бар показывает, сколько уже потрачено, и
подсвечивает превышение.

### Регулярные платежи
Подписки и счета, которые повторяются. Приложение само создаёт операцию в день
списания и заранее присылает системное уведомление о предстоящем платеже.

### Цели
Накопительная цель привязывается к счёту, показывает прогресс и, при желании,
срок.

### Аналитика
Динамика доходов и расходов по месяцам, чистый результат, разбивка трат по
категориям.

### Обзор
Стартовый экран собирает главное: общий баланс, лимит расходов на месяц,
ближайшие платежи, цели, бюджеты под угрозой, последние операции и **прогноз
баланса на конец месяца** — сколько останется с учётом предстоящих регулярных
платежей и текущего темпа трат.

### Прочее
- Тёмная и светлая тема с переключателем.
- Запуск вместе с системой и сворачивание в трей вместо закрытия — чтобы
  напоминания и автосоздание платежей работали, даже когда окно закрыто.
- Валюта (₽, $, €) выбирается в настройках.

## Где лежат данные

Всё хранится в файле `fincy.db` в папке приложения
(`%APPDATA%\com.rowvybeats.fincy\` в Windows). Скопируйте этот файл, чтобы
сделать резервную копию или перенести данные на другой компьютер.

## Сборка из исходников

Нужны [Node.js](https://nodejs.org/) 20+, [Rust](https://www.rust-lang.org/)
(stable) и [системные зависимости Tauri](https://tauri.app/start/prerequisites/).

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # сборка установщика в src-tauri/target/release/bundle/
```

Стек: Tauri v2, React 19 + TypeScript, SQLite (`@tauri-apps/plugin-sql`),
TanStack Query, Recharts, Tailwind CSS v4.
